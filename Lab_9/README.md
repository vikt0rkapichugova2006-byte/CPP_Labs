# Лабораторная работа №9. Структуры и массивы структур

#Вариант 16
Тема: Расписание маршрутов электропоездов.

# Условие задачи
Определить структурный тип, описывающий расписание маршрутов электропоездов:
- Название маршрута
- Пункт отправления
- Пункт прибытия
- Время отправления/прибытия
- Количество вагонов
- Тип электропоезда (enum: пассажирский, товарный, ремонтный, др.)

Требования:
1. Заполнить массив из 20 записей (инициализация в коде).
2. Использовать вложенную структуру (`Time`) и перечисление (`enum`).
3. Отфильтровать пассажирские поезда, идущие в туристические города.
4. Отсортировать отфильтрованный массив по пункту отправления (пузырьком).
5. Вывести данные конкретного поезда и 3 самых коротких состава.
6. Реализовать функцию изменения данных.

# Используемые технологии
- C++ (Standard C++11 or higher)
- Структуры (`struct`)
- Массивы структур
- Алгоритм сортировки пузырьком

# Как запустить
1. Скомпилировать файл `main.cpp`.
2. Запустить исполняемый файл.
3. Программа выполнит все действия автоматически и выведет результаты в консоль.
