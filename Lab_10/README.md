# Лабораторная работа №10. Работа с файлами

# Вариант 16
Тема: Чтение и запись расписания поездов в файлы.

# Условие
На основе решения Занятия 9 реализовать:
1. Считать из текстового файла `updates.txt` новые значения количества вагонов и обновить массив в памяти.
2. Реализовать запись всей структуры массива в бинарный файл `routes.bin` и чтение из него обратно.

# Формат файлов
- `updates.txt`: Текстовый файл, содержит пары "НазваниеПоезда КоличествоВагонов".
- `routes.bin`: Бинарный файл, содержит полный массив структур `Route`.

# Результат выполнения
1. Программа считывает `updates.txt` и обновляет данные в консоли.
2. Программа создает файл `routes.bin` с данными всех поездов.
3. Программа считывает `routes.bin` обратно и подтверждает успешную загрузку.
